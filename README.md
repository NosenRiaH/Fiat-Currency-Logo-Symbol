NOSENVN FINANCE — ORIGINAL WORLD CURRENCY ICON SET

178 outlined SVG icons, one for every code in the ISO 4217 current currency and funds register published 2026-09-17. This includes national/shared currencies plus fund, metal, accounting and special codes. Not all 178 are spendable national currencies.

Style: colored circles, white symbols, long diagonal shadows. USD and VND lead the preview. Distinct ISO codes are used for currencies without a suitable dedicated symbol. These are custom UI symbols, not official central-bank logos.
